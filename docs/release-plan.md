# План релизов

Фактическая сводка и DEC находятся также в
[`reports/sprint-6-5-release-management.md`](reports/sprint-6-5-release-management.md).
План не переводит функцию в статус «готово» без кода и проверки.

| Версия | Статус | Ценность | Демонстрационный сценарий | Последний шаг: проверка отказа |
| --- | --- | --- | --- | --- |
| v0.2.0 | факт | регистрация и JWT | регистрация → код → подтверждение → вход | неверный код/пароль не выдаёт сессию |
| v0.4.0 | факт/MVP | профиль, каталог, групповой чат | login → профиль → навыки → каталог → чат | запрос без JWT получает 401; соединение без авторизации отклонено |
| v0.6.0 | план | avatar upload, личные сообщения, история | изображение → match → личный диалог | чужой пользователь не читает диалог; неверный файл отклонён |
| v0.8.0 | план | права, модерация, уведомления | роль модератора выполняет действие | действие без права возвращает 403 |
| v1.0.0 | план | стабильный MVP | чистый deploy → smoke test → recovery | сбой health блокирует rollout |
