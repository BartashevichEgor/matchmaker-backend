# План релизов

| Версия | Ценность | Демонстрационный сценарий | Критерий отказа |
| --- | --- | --- | --- |
| v0.2.0 | регистрация и JWT | регистрация → код → вход | неверный код не создаёт сессию |
| v0.4.0 | профиль, каталог, групповой чат | вход → профиль → каталог → мэтч → чат | недоступная БД даёт `/health` 503 |
| v0.6.0 | качество клиента, аватар, личные сообщения | обновить профиль → загрузить аватар → открыть личный чат | пользователь без доступа не входит в диалог |
| v0.8.0 | уведомления и модерация | мэтч → уведомление → принятие | повторное событие не дублирует уведомление |
| v1.0.0 | стабильный MVP | полный сценарий на двух машинах | failure-сценарии отражены в тестах |
