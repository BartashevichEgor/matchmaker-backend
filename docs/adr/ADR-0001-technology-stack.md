# ADR-0001: FastAPI, React, PostgreSQL и Docker

**Статус:** принято. **Контекст:** нужен учебный MVP с документируемым REST API, web-клиентом и воспроизводимым запуском.

**Решение:** FastAPI + Pydantic для API, React + TypeScript + Vite для web, PostgreSQL для постоянных данных, SQLite для быстрых тестов, Docker Compose для одинакового окружения. JWT остаётся механизмом доступа; Redis подключается опционально для лимитов.

**Альтернативы:** Django/DRF даёт больше встроенных компонентов, но сложнее для компактного API; Spring требует больше инфраструктуры; MongoDB хуже соответствует транзакционным связям проекта–кандидата–мэтча. Отказ от Docker делает запуск менее повторяемым.

**Отказы:** клиент применяет тайм-аут и показывает безопасную ошибку; health endpoint возвращает `503` без деталей; повторные действия (свайп, join) идемпотентны. Очередь пока не нужна: отправка почты и чат ограничены MVP; при росте нагрузки почтовые задания будут вынесены в worker с повторными попытками.

**Последствия:** разработчикам требуются Python и Node; миграции должны поддерживать PostgreSQL и SQLite. Решение пересматривается при появлении фоновых задач с гарантированной доставкой или при отдельном мобильном release-пайплайне.
