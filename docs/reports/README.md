# Отчёты по спринтам Matchmaker

Эти материалы подготовлены как доказательная база для Moodle. Каждый файл
содержит разделы с кодами заданий курса; его можно приложить целиком либо
скопировать нужный раздел в текстовое поле задания. Факты опираются на Git,
код и документацию. Показатели Jira (SP, план/факт времени, номера карточек и
скриншоты доски) намеренно не подменяются: их надо добавить из фактической
доски перед сдачей.

## Правило достоверности

Не указывайте как выполненное то, чего нет в коде или на доске. На 26.11.2026
нет реализации загрузки изображения-аватара на backend. Приватные диалоги и
история сообщений реализованы в актуальном `chat-service`; их DB-интеграционные
тесты требуют PostgreSQL и при локальном запуске без него пропускаются.
