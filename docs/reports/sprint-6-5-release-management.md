# Отчёт 6/5 — план релизов и управление изменениями

Дата среза: 26.11.2026. План не подменяет факт: версии с пометкой «план»
не являются поставленными релизами.

| Версия | Статус | Ценность | Сценарий готовности | Последний шаг — проверка отказа |
| --- | --- | --- | --- | --- |
| v0.2 | факт (Sprint 4) | регистрация и безопасный вход | register → получить код → verify → login → JWT | login с неподтверждённым e-mail или неверным паролем возвращает ошибку и не выдаёт сессию |
| v0.4 | факт/MVP (Sprint 5–6) | профиль, навыки, каталог, приватный chat backend | login → PATCH profile → skills → GET/POST projects → match → чат | запрос без Bearer JWT получает 401; посторонний не получает доступ к диалогу |
| v0.6 | план | avatar upload и UI-интеграция чата | загрузить безопасное изображение → открыть существующий диалог | неподдерживаемый файл отклонён; пользователь вне диалога не может читать/писать |
| v0.8 | план | роли/права, модерация, фильтры и уведомления | администратор модерирует сущность, участник видит разрешённые действия | действие без роли возвращает 403 и не меняет данные |
| v1.0 | план | release candidate, наблюдаемость и резервное восстановление | чистое развёртывание → smoke-test → rollback/recovery test | искусственный сбой health/dependency блокирует rollout и фиксируется в мониторинге |

## DEC — журнал решений по изменениям

| DEC | Решение | Причина | Последствие |
| --- | --- | --- | --- |
| DEC-01 | FastAPI + PostgreSQL — ядро API | компактный стек и строгая валидация | OpenAPI генерируется из runtime |
| DEC-02 | Модульный монолит для REST, отдельный Node.js сервис для WebSocket | маленькая команда, но отдельный transport чата | приватная история и read-state реализованы; UI и production deployment остаются следующими задачами |
| DEC-03 | OpenAPI-first для web и KMP | снизить риск рассинхрона JSON | изменение endpoint начинается со схемы и теста |
| DEC-04 | Локальный outbox для разработки e-mail | повторяемый учебный сценарий без внешней почты | production SMTP не заявляется реализованным |
| DEC-05 | Avatar fallback — инициалы, не загрузка файла | backend storage/валидация не готовы | upload остаётся в v0.6 |
| DEC-06 | Личные сообщения выделяются отдельным сервисом с проверкой доступа | разные права, модель данных и приватность | реализован отдельный инкремент с негативным e2e-тестом; остаётся UI |
