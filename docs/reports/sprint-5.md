# Спринт 5 — риски, чат и документация (26.10–08.11.2026)

## 5/S1. Бэклог Sprint 5

Цель: снизить риски интеграции, подготовить групповой чат и привести
репозиторий к формату Docs as Code. Приоритеты: план рисков, WebSocket MVP,
дизайн и web-форма чата, документация архитектуры и релизный контур.

Для Moodle нужен скрин Jira с реальными колонками Product Backlog и Sprint
Backlog, SP и приоритетами; этот текст не заменяет такой скриншот.

## 5/S3. Scrum meeting 10 — неделя 10

Решение команды: source of truth для HTTP-контракта — FastAPI/OpenAPI;
клиенты не дублируют собственные варианты JSON. Групповой чат реализуется
отдельным Node.js WebSocket-сервисом, при этом REST API и PostgreSQL остаются
в core-api. На следующую неделю — реальная сквозная проверка регистрации,
каталога и чата, а также подготовка релизных документов.

## 5/S4. Sprint Review и Retrospective

**Готово по коду:** репозиторная документация, WebSocket-групповой чат
(`chat-service`), OpenAPI и health/deploy-контур. **Ограничения:** не доказана
постоянная история сообщений; личные сообщения не реализованы. Принимаются
только те карточки, для которых есть код, тест или демонстрационный сценарий.

**Хорошо:** выделение документации в `docs/` и самостоятельный чат-сервис
снизили связанность; явные планы фаз помогли согласовать работу web и API.

**Улучшение:** перед merge менять OpenAPI, добавлять негативный тест и указывать
в PR способ ручной проверки. Избегать закрытия задачи только по макету без
работающего API-вызова.

## 5/2. Backend-чата — часть 1

Групповой WebSocket-сервис находится в [`chat-service/`](../../chat-service/).
В нём есть отдельный `package.json`, сервер и протокольный тест. Это именно
групповая рассылка MVP; не заявляется, что реализованы личные сообщения или
надёжное долговременное хранение истории.

## 5/3. Дизайн чата — часть 1

Требования дизайна: список сообщений с автором/временем, поле ввода, понятное
состояние подключения и безопасная ошибка вместо молчаливого падения. До
прикрепления ссылки на актуальный frame Figma в Moodle укажите её из аккаунта
команды; в Git прямого артефакта от Вероники нет.
