# C4-диаграммы

- `c4-context.puml` — уровень 1, граница продукта и пользователи;
  `c4-context.svg` — переносимое представление для отчёта.
- `c4-container.puml` — уровень 2, браузер, nginx, FastAPI, PostgreSQL и
  запланированные сервисы; `c4-container.svg` — переносимое представление.

Файлы PlantUML — источник истины и хранятся рядом с кодом, поэтому их изменение
проходит review вместе с изменением архитектуры. SVG не редактируются вручную
как архитектурный источник: они нужны для Moodle/Drive и быстрого просмотра.
